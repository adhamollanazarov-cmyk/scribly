# Phase 5 review — 2026-10-13

Reviewed `main` at `4be9dda` (Phase 5 overlay + library + new mascot merged) against
AGENTS.md and `docs/SPEC.md` Phase 5. Written by Claude Code on `claude/phase5-review`
(the founder asked for a Claude branch instead of `codex/`). **No code was changed.**
`MOCK_AI=1` only. No Anthropic, TTS or other network calls. No screenshot of the real
screen was kept.

Focus areas: Electron security (context isolation, CSP, preload API, the `app://`
proxy limited to two paths, navigation and permission blocking), region → board mapping
at 100/125/150 %, the screenshot never written to disk, and the global Esc released after
a lesson.

Besides reading the code, a temporary Playwright-Electron probe (not committed) drove
the built app against a local stub server: hotkey → selector → page-side attacks →
drag → a one-step lesson played to `finished` → close. Results are quoted as **probe**
below.

## Findings

| ID | Severity | File:line | Problem / evidence | Suggested fix |
|---|---|---|---|---|
| M1 | med | `desktop/src/main/overlay.ts:135`, `web/src/overlay/LessonOverlay.tsx:144` | **The global Esc is never released after a lesson ends on its own.** Esc is registered globally for the whole time the overlay window exists, and only `closeAll()` unregisters it. Nothing closes the overlay when the player reaches `finished`: it stays always-on-top and click-through, so the user goes back to work while Esc is taken from every other app (dialogs, editors, full-screen video) until they find the pill's close button or press Esc once more. **Probe:** status `finished`, then 3 s later: window open = true, `globalShortcut.isRegistered('Escape')` = true, `overlayActive` = true. After a dismiss it is false (released correctly on close). DECISIONS says Esc is global "only briefly so other apps keep it"; a finished lesson breaks that. | Pick one: (a) Scribbly leaves on its own some seconds after `finished` (send `closeLesson` after the disappear motion, cancelled if the pointer is over the board or pill); or (b) unregister Esc once the page reports `finished` and keep the pill's close button and an Esc on the focused window as the way out. Add a smoke-test step: lesson finished → Esc released or window closed. |
| L1 | low | `server/app/routes/explain.py:48–65` | **A rejected screenshot is echoed back.** On a validation failure FastAPI's default 422 body includes `"input": "<the whole base64 image>"`. Reproduced with `TestClient` in mock mode: the 422 response contains the posted `image_png_base64` verbatim. Nothing is written to disk and the overlay drops the body (`StreamError('bad_request')`), but this copies the screenshot into a response that proxies or debug logging could keep, and that can be up to about 11 MB. | Return a 422 without `input` for this route: validate the image in the handler and raise `HTTPException(422, "image must be a PNG …")`, or add a `RequestValidationError` handler that strips `input`. Add a test that the 422 body does not contain the posted value. |
| L2 | low | `desktop/src/main/main.ts:22–27, 103, 117`; `desktop/electron-builder.yml` | **The packaged app honours dev/test environment variables.** `SCRIBBLY_RENDERER_URL` loads any URL into the overlay window with the `window.scribbly` bridge, and it also skips `handleScheme`, so the `app://` CSP and proxy are gone. `SCRIBBLY_E2E=1` exposes test hooks on `globalThis` and turns off the single-instance lock. `SCRIBBLY_SERVER` sends screenshots to any host. Electron fuses are not configured (`RunAsNode`, `EnableNodeOptionsEnvironmentVariable`, `EnableNodeCliInspectArguments` stay on). Exploiting this needs control of the user's environment, i.e. local access, hence low. | Read these variables only when `!app.isPackaged`, or keep `SCRIBBLY_SERVER` but limit it to `127.0.0.1`/`localhost`. Set `electronFuses` in `electron-builder.yml` (runAsNode off, NODE_OPTIONS off, inspect args off, cookie encryption and asar integrity on). |
| L3 | low | `desktop/src/main/main.ts:23`, `desktop/src/main/protocol.ts:92` | **The screenshot goes to whatever listens on `127.0.0.1:8000`.** The installer does not ship the server, and 8000 is a common development port. If the Scribbly server is not running but another local dev server is, the region capture is POSTed to that server. No server identity is checked. | Before the first POST, check `GET /health` for a Scribbly marker (for example `{"app":"scribbly"}`), or use a less common default port. Ideally give the server and the app a shared random token when the server is bundled. |
| L4 | low | `desktop/src/main/overlay.ts:137` | The return value of `globalShortcut.register('Escape', …)` is ignored. If another app holds a global Esc, the selector still cancels with its own keydown (`Selector.tsx:12`, the window is focused), but the click-through lesson window cannot get keyboard focus, so Esc silently does nothing. Only the pill's close button works. | When registration fails, show a one-line hint on the pill ("Close with ✕"), or log it. Low impact while M1 is open. |
| L5 | low | `desktop/src/main/windows.ts:26–54` | **Page zoom is not locked (code reading, not verified live).** The selector reports regions in CSS px, and the code assumes CSS px = DIP. Chromium's Ctrl+wheel page zoom on the focused selector window would break that. `sanitizeRegion` clamps to the display, so the capture would cover a different area than the one drawn. `setMenu(null)` removes the zoom accelerators but not wheel zoom. | `win.webContents.setVisualZoomLevelLimits(1, 1)` plus `setZoomFactor(1)` on `did-finish-load` (or reject `zoom-changed`), and have the page send `window.devicePixelRatio`/`innerWidth` with the region so main can reject a mismatch. |
| L6 | low | `desktop/src/main/capture.ts:15` | If every capture source has an empty `display_id`, the fallback matches screens by index. `desktopCapturer` and `screen.getAllDisplays()` order is not guaranteed to be the same, so a multi-monitor setup could capture the wrong screen in that case. Covered by unit tests only. | When ids are missing, match by thumbnail aspect/size against `display.size × scaleFactor` before falling back to the index. If several match, fail closed. |
| I1 | info | `web/src/main-overlay.tsx:14` | In dev (`SCRIBBLY_RENDERER_URL` → Vite), `StrictMode` mounts the lesson effect twice, so the screenshot is POSTed twice and the first request is aborted. Production builds are unaffected (no double effects). This contradicts "sent once" only in dev. | Acceptable. Optionally guard the request with a ref so dev matches production. |
| I2 | info | `desktop/src/main/protocol.ts:12` | The CSP has no explicit `frame-src`/`worker-src`. They fall back to `default-src 'self'`. Framing is already blocked by `frame-ancestors 'none'` (**probe:** an `app://scribbly/overlay.html` iframe loaded as a blocked, cross-origin error frame, and the bridge was unreachable). | Optional: add `frame-src 'none'; worker-src 'none'` to make intent explicit. |

No high-severity issues found.

## Verified (no finding)

| Area | Evidence |
|---|---|
| Context isolation / no Node | `secureWebPreferences` (`windows.ts`): `contextIsolation`, `sandbox`, `nodeIntegration(InWorker)` off, `webSecurity` on, `webviewTag` off, devTools only when unpackaged. Smoke test: no `require`/`process`/`module`/`Buffer`/`ipcRenderer` on `window`. |
| Preload API | Exactly 4 calls (`onMode`, `selectRegion`, `setInteractive`, `closeLesson`). `ipcRenderer` is never exposed. Main handlers are guarded by `overlay.owns(event.sender)`. `selectRegion` goes through `sanitizeRegion` (finite numbers, clipped, ≥ 24 DIP). `setInteractive` accepts only `=== true`. |
| `app://` proxy limited to 2 paths | `routeFor`: `POST /explain-region` and `GET /audio/<64 hex>.mp3` only; everything else is a file under the renderer root or 403. **Probe:** `POST /lessons` 403, `GET /explain-region` 403, `POST /audio/…` 403, `GET /health` 404 (file), `/%2e%2e/package.json` and `/..%5c..%5cpackage.json` 404. The stub server saw only the two `GET /audio/…` requests, and a `?x=../lessons` query was dropped before proxying. Request headers forwarded: only content-type/accept/range. |
| CSP | Sent on every file response: `script-src 'self'`, `connect-src 'self'`, `object-src 'none'`, `base-uri 'none'`, `frame-ancestors 'none'`. **Probe:** direct `fetch` to the server URL and to `https://example.com` both fail (connect-src). Smoke test: injected inline script does not run. `style-src 'unsafe-inline'` is a documented KaTeX need. KaTeX `trust` is not enabled. |
| Navigation / popups | `will-navigate` and `will-attach-webview` prevented, `setWindowOpenHandler` denies. **Probe:** `location.href = 'https://example.com/'` and `= 'app://scribbly/index.html'` both leave the page on `overlay.html`. `window.open` returns `null` and no window is created. |
| Permissions | Request and check handlers deny everything on the default session (the overlay uses it). **Probe:** microphone `NotAllowedError`, `getDisplayMedia` `NotAllowedError`, notifications `denied`, clipboard read `NotAllowedError`. Capture runs only in main via `desktopCapturer`. |
| Screenshot never on disk | `captureRegion` returns base64 in memory. Main → page by IPC, page → `net.fetch` POST (never cached), server validates and `del`s it (`explain.py:84`), no logging of the body. **Probe:** after a full lesson, none of the 76 files under the run's `userData` (Chromium caches, local storage, settings) contain the capture's IDAT bytes or a base64 slice of it. The server-side echo is L1. Not checked: Windows crash dumps and swap. |
| Region → capture at 100/125/150 % | `cropRect` scales by the real capture size / display DIP size, so no nominal factor is trusted, and it rounds outwards. Unit tests cover 100/125/150 %, a downscaled 4K capture and the fractional-pixel edge (`geometry.test.ts`). `fitWithin` limits uploads to 1600 px. Smoke test (live, 125 %): the PNG's aspect ratio matches the 400×260 DIP drag. **Only 125 % and one monitor exist on this machine**, so 100/150 % and mixed-DPI multi-monitor are unit-tested only. |
| Region → board | `boardPlacement` puts the board exactly over the region (or grows it to 560×350 around its centre, kept on screen). `boardToWindow`/`viewTransform` match the SVG's `meet` letterboxing. Smoke test: board `left` 40 px, width 560 px for a 400 px drag at x = 120 (grown around the centre). |
| Esc lifecycle (apart from M1) | **Probe:** not registered before the hotkey; registered during selection; released after the dismiss → close path. `will-quit` unregisters all. Capture racing with Esc or a second hotkey is safe (`win.isDestroyed()` check after the await). The dismiss fallback closes after 1.5 s if the page never answers. |
