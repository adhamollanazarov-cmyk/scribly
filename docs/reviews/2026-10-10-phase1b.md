## Scope and evidence

The grammar fallback is implemented by selecting the lean skeleton **up front**, not
by issuing a full-schema call and retrying a grammar-size 400. Existing tests verify
the inlined schemas' property budget, required fields, no unions/unsupported keywords,
and per-item conversion. API acceptance of that grammar was not re-tested. Runtime
Pydantic/template/reference checks remain authoritative; H2 closes holes in that boundary.

The new `symbol` primitive is consistent across schema docs, models, generated JSON
Schema and the Gauss fixture. Regenerating the schema produced no diff. Golden/replay
fixtures validate in the offline suite. No lesson-contract fields or dependencies were
changed by this review. `manual_checks` and grading version are eval metadata only.

New tests cover ledger override attempts, primitive/group collisions, forbidden metadata,
one-call step repair, final-error SSE behavior, signed/unit-aware grading, unused results,
displayed rounding, warning/manual-review gates, unit-parser bounds, and historical-score
warnings. Six initial boundary regressions failed before fixes; those regressions now pass.

The unit converter accepts a restricted SI arithmetic grammar (`*`, `/`, integer powers,
known units/prefixes), never evals code, and fails closed on unknown/incompatible units.
Tests cover every expected unit currently in the 30-problem bank. Numeric matching still
does not prove that a value belongs to a named quantity or that prose/arrows agree with
it. The Kirchhoff manual gate is deliberately conservative; the prompt change is a
safeguard, not proof that future generated directions are correct. Other semantic claims
still need physics review. The old **30/30** report is historical evidence under the old
grader, not a result reproduced or certified by this review.
